# Assignment 2 - Read Me

# Purpose/Goal

The goal is to enable someone to better monitor the different feedback and responses that can come into a customer/public facing inbox.

Considering the variety and frequency of responses, it is challenging to constantly monitor the inbox to assess how the brand/company is perceived.

But using a chatbot powered by natural language processing, it can accelerate someone's capabilities in understanding customer sentiment in order to continue or pivot towards a new direction.
